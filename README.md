# hockey_kr

## ICE RUSH

설치 없이 브라우저에서 플레이하는 WebGL 3D 아이스하키 프로토타입. 각 팀은 스케이터 5명(LD/RD 수비, LW/RW/C 공격)과 자동 골리 1명으로 구성됩니다.

## 실행

GitHub에서 **Code → Download ZIP**으로 받고 압축을 푼 뒤 `index.html`을 Chrome 또는 Edge에서 엽니다. 외부 라이브러리, 서버, API 키가 필요하지 않습니다.

## 조작

| 키 | 동작 |
| --- | --- |
| WASD / 방향키 | 스케이팅 |
| C | 공격 중 패스 / 수비 중 퍽에 가장 가까운 스케이터로 전환 |
| X | 조작 선수가 퍽을 소유하면 패스 / 없으면 가까운 상대 퍽 스틸 |
| Space 길게 | 충전 슛 |
| Z / V | 좌우 드리블 |
| 왼쪽 Shift | 스프린트 |
| B | 바디 체킹 (인터피어런스·차징·트리핑 주의) |
| Esc | 일시정지 |

C의 공격/수비 판단은 **팀의 퍽 소유 상태**를 기준으로 합니다. 우리 팀의 패스가 이동 중이면 추가 패스를 보내거나 선수를 바꾸지 않고 리시브를 기다립니다. 소유자가 없는 루스 퍽은 C로 가장 가까운 선수를 선택할 수 있습니다. 골리는 전환 대상에서 제외합니다. 패스를 받거나 퍽을 확보한 선수로 조작이 자동 전환됩니다. 모바일 터치 버튼에도 같은 동작을 적용합니다.

## 팀 전술 AI

고정 포지션 구역과 강제 경계를 제거했습니다. 사용자는 모든 스케이터를 빙판 전체에서 자유롭게 움직일 수 있습니다. AI도 이동 가능한 구역을 제한하지 않고 상황별 목표를 정해 관성 스케이팅으로 이동합니다. 경기장 보드와 골리의 크리스 범위만 경계로 유지합니다.

팀 전술 조정기가 퍽 소유, 위치, 패스 진행, 상대 압박, 동료 위치를 읽고 다섯 명에게 서로 다른 역할을 배정합니다. 외부 모델 호출 없이 브라우저에서 실행되는 규칙 기반 게임 AI입니다.

- **공격 연결:** 센터는 퍽 주변에서 패스를 받을 위치를 찾습니다. 퍽 쪽 윙은 가까운 지원을, 반대쪽 윙은 골문 앞 침투를 맡습니다. 수비수는 후방 패스 옵션을 유지합니다.
- **수비 진영 탈출:** 센터가 낮은 위치에서 연결하고 윙이 양측으로 벌어져 패스 출구를 만듭니다.
- **수비수 침투:** 한 명의 수비수만 AI가 공격에 합류합니다. 센터가 빈 수비 위치를 커버하고 다른 수비수는 뒤에 남습니다. AI 수비수는 센터가 커버 위치에 접근할 때까지 기다린 뒤 침투합니다. 사용자가 수비수를 몰고 올라갈 때도 센터에게 커버를 배정합니다.
- **깊은 수비:** 센터는 블루라인이나 중앙 레인에 묶이지 않고 자기 골문 근처까지 내려와 수비수와 골문 앞 공간을 지원합니다. 윙은 상대 수비수와 패스 길을 마크합니다.
- **전방 압박:** 한 명이 퍽을 압박하고 다른 공격수가 근처를 지원합니다. 남은 선수는 역습에 대비합니다.
- **소유권 상실:** 침투한 수비수는 복귀하고 센터는 그 수비수가 실제로 돌아올 때까지 커버를 유지합니다. 루스 퍽에는 가까운 선수와 리바운드 지원을 배정합니다.
- **간격 유지:** 동료 사이 간격을 유지하는 이동 보정과 패스 길의 상대 위치를 고려한 패스 선택을 적용합니다. 같은 전술을 상대 팀의 공격 방향에 맞춰 반전합니다.

사용자가 조작 중인 선수는 AI가 강제로 이동시키지 않습니다. 포지션 표기는 원래 역할이고 실제 움직임과 임시 담당은 상황에 따라 바뀝니다. 민트 링은 조작 선수입니다. 경기 아래에 현재 공수 상황과 수비수 침투/센터 커버 상태를 표시합니다.

## 전술 참고 자료

- [Ice Hockey Systems / Denis Savard: Defensive Zone Coverage – Protect the House](https://www.icehockeysystems.com/hockey-systems/defensive-zone-coverage-protect-house): 골문 앞 보호, 퍽 압박과 낮은 지원, 퍽이 이동할 때 역할을 교대하는 원칙을 참고했습니다.
- [Ice Hockey Systems: 2-1-2 Forecheck – Strong Side Support](https://icehockeysystems.com/print/system/with-notes/183): 수비수가 내려갈 때 높은 위치의 공격수가 빈 수비 자리를 맡는 회전을 참고했습니다. 이 게임에서는 요청에 따라 그 역할을 센터에 우선 배정합니다.

자료의 원칙을 5인 게임에 맞춰 구현한 전술 AI이며, 특정 실제 팀의 전술 전체를 재현하는 시뮬레이터는 아닙니다.

## 경기 모드

- 단판: 3피리어드, 동점 시 골든골 연장
- 리그: 8개국 단일 라운드 로빈, 7라운드, 승점 및 득실차 순위
- 월드컵: 8강 → 4강 → 결승

## 갤럭시 터치 플레이

가로 화면을 권장합니다. 왼쪽 가상 스틱으로 이동하고 오른쪽은 **슛(길게 눌러 충전), 패스/스틸, 패스/선수 전환 3개 버튼**으로 구성합니다. 체킹·가속·좌우 드리블은 기존 키보드 키로 사용할 수 있습니다. 이동하면서 슛을 충전하는 동시 터치를 지원합니다. 기본 화면은 이전 전체 보기보다 가로·세로 시야 범위를 절반으로 줄인 약 2배 확대이며, 카메라가 퍽의 좌우·상하 이동을 부드럽게 따라갑니다. 빠른 슛과 페이스오프에서도 퍽이 화면에 남도록 추적 지연을 제한합니다. 상단에서 전체 화면, 전체 보기/퍽 추적 전환, 규칙 안내를 사용할 수 있으며 경기 시작 메뉴에서 화질을 선택합니다. 화면 회전 잠금은 브라우저 지원에 따라 달라집니다.

단일 HTML에 코드와 3D 모델이 모두 포함되어 인터넷 연결이나 외부 라이브러리가 필요 없습니다. ZIP을 압축 해제한 뒤 `index.html`을 WebGL을 지원하는 Chrome 또는 Samsung Internet으로 여세요. 휴대폰의 파일 미리보기 앱에서는 실행되지 않을 수 있습니다. PC에서 같은 Wi-Fi로 테스트하려면 프로젝트 폴더에서 `python -m http.server 8000 --bind 0.0.0.0`을 실행하고 휴대폰 브라우저에서 `http://PC의내부IP:8000`으로 접속할 수 있습니다. PC 방화벽에서 로컬 네트워크 접속이 허용되어야 합니다.

## 3D와 규칙

- 실제 WebGL 입체 경기장, 보드, 골대와 네트, 관절이 움직이는 선수와 스틱, 스케이팅 스트라이드와 몸 기울기, 슛 동작, 골리 세이브 자세.
- 오프사이드: 공격 블루라인 진입, 지연 오프사이드와 태그업, 반칙 위치에 따른 페이스오프.
- 아이싱: 센터라인 이전에서 보낸 퍽의 골라인 통과, 터치와 수적 열세 면제, 공격/수비의 퍽 접근 거리를 이용한 간소화된 하이브리드 판정.
- 인터피어런스, 차징, 뒤에서의 위험한 스틸/체킹에 따른 트리핑 판정. 게임용 거리·속도·방향 기준으로 판정합니다.
- 요청에 맞춘 **90초 마이너 페널티**: 해당 선수 퇴장, 파워플레이/페널티킬, 최소 3명의 스케이터와 추가 페널티 대기, 파워플레이 실점 시 마이너 해제. 경기 중단과 일시정지 중에는 퇴장 시간도 멈춥니다.
- 골리의 퍽 캐치와 페이스오프, 골라인 기준 득점.

[IIHF 규칙](https://www.iihf.com/en/statichub/4719/rules-and-)과 [NHL 비디오 룰북](https://www.nhl.com/info/video-rulebook)을 참고한 간소화된 구현입니다. **공식 마이너 페널티는 2분**이며 이 게임은 사용자 요청으로 1분 30초입니다. 메이저·미스컨덕트, 비디오 판독, 지연 페널티, 정식 교대 및 모든 세부 심판 절차를 구현한 공식 규칙 시뮬레이터는 아닙니다.

## 검증과 현재 범위

Chromium에서 실제 WebGL 렌더링, 규칙별 판정, 퇴장 및 복귀, 동시 터치, 터치 취소, 모바일 화면 배치, 리그와 토너먼트를 자동 검증합니다. 갤럭시 크기의 가로·세로 화면을 에뮬레이션하며, 실제 갤럭시 기기의 성능과 브라우저 파일 열기는 별도 확인이 필요합니다.

브라우저용 플레이 가능 프로토타입입니다. 실제 팀 로스터, 온라인 멀티플레이, 오디오, 진행 저장, Android APK 및 Play 스토어 배포는 포함하지 않습니다. 페이지를 새로고침하면 시즌이 초기화됩니다.
